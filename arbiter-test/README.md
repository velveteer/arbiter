# arbiter-test

Shared test support for Arbiter. Use it to test a `MonadArbiter` backend of your own.

Schema setup: [`Arbiter.Test.Setup` Haddocks](https://arbiterq.dev/arbiter-test/Arbiter-Test-Setup.html). Backend suites: [`Arbiter.Test.Operations` Haddocks](https://arbiterq.dev/arbiter-test/Arbiter-Test-Operations.html).

Worker conformance: build a `TestBackend` for your backend and pass it to the specs. Setup and spec list: [`Arbiter.Worker.TestKit` Haddocks](https://arbiterq.dev/arbiter-test/Arbiter-Worker-TestKit.html).
